Currently in force: 1. Where model calls serialise on one GPU, a second turn spends its time queued and silent - which is exactly what gets a run aborted for silence. Raise this only where turns genuinely run in parallel.
ISO-8601, e.g. PT15M for 15 minutes, PT1H for one hour. In force: idle PT15M, max PT1H, grace PT2M. A run is stopped for producing nothing for the idle timeout - wall-clock elapsed time is not the signal, since one model call on a contended GPU has been measured at 278 seconds. Keep max duration comfortably above idle timeout, or silence stops being the deciding bound.
Where the agent works. One directory per card is created beneath this path, on the agent's own filesystem - Petri never opens it. In force: /workspaces/petri.
